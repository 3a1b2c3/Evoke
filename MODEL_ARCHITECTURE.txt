                        DiT BLOCK STRUCTURE

INPUT PROCESSING

│ │   and 384/8=48, 640/8=80 spatial dims              │
│ └─ Kernel: learnable projection                      │
│                                                      │
│ Flatten & Tokenize                                   │
│ └─ (1, 4, 48, 80, 16) → (1, 3840, 2048)             │
│     [seq_len=3840, hidden_dim=2048]                  │
│                                                      │
│ Add Conditioning                                     │
│ ├─ Text embeddings (77 tokens × 2048)               │
│ ├─ Timestep embeddings                               │
│ ├─ Position embeddings (RoPE)                        │
│ └─ Merged with self-attention                        │
└──────────────────────────────────────────────────────┘
           ↓
┌──────────────────────────────────────────────────────┐
│                 TRANSFORMER STACK                    │
│                 (28 DiT Blocks)                      │
│                                                      │
│ Each DiT Block:                                      │
│ ┌────────────────────────────────────────────────┐   │
│ │ [1] Layer Norm                                 │   │
│ │     └─ Input shape: (1, 3840, 2048)           │   │
│ │                                                │   │
│ │ [2] Multi-Head Self-Attention (8 heads)        │   │
│ │     ├─ Query, Key, Value projections           │   │
│ │     ├─ Head dim: 2048 / 8 = 256               │   │
│ │     ├─ KV Cache: store K, V for next steps     │   │
│ │     │  (reuse in diffusion steps 2-3)          │   │
│ │     ├─ Attention output: (1, 3840, 2048)       │   │
│ │     └─ Operation: softmax(Q @ K^T / √d) @ V   │   │
│ │                                                │   │
│ │ [3] Layer Norm                                 │   │
│ │                                                │   │
│ │ [4] Gated MLP (FFN)                            │   │
│ │     ├─ Hidden dim: 5376 (2.625× expansion)     │   │
│ │     ├─ Gates for conditional scaling           │   │
│ │     └─ Output: (1, 3840, 2048)                 │   │
│ │                                                │   │
│ │ [5] Residual Connections                       │   │
│ │     └─ x = x + attn(ln(x)) + mlp(ln(x))        │   │

│                                                      │

│                                                      │

│ └─ Per block: ~38.3M                                │
│                                                      │
│ Total for 28 blocks: 28 × 38.3M ≈ 1.07B             │
└──────────────────────────────────────────────────────┘
           ↓
OUTPUT LAYER

================================================================================
                      ATTENTION MECHANISM (detailed)
================================================================================

Self-Attention with KV Cache
┌────────────────────────────────────────────────────────┐
│ Input: Sequence (1, seq_len=3840, hidden=2048)        │
│                                                        │
│ Projection:                                            │
│ ├─ W_q @ x → Q (1, 8 heads, 3840, 256)               │
│ ├─ W_k @ x → K (1, 8 heads, 3840, 256)               │
│ └─ W_v @ x → V (1, 8 heads, 3840, 256)               │
│                                                        │
│ KV CACHE (for diffusion steps):                        │
│ ├─ Step 1: compute K, V, store in cache               │
│ ├─ Step 2-3: reuse K, V from cache                    │
│ │   [reduces computation: O(n²) per step]             │
│ └─ Cache size: 2 × (8 heads, 3840, 256) = ~25MB      │
│                                                        │
│ Attention Computation:                                 │
│ ├─ Scores = softmax(Q @ K^T / √256)                  │
│ ├─ Output = Scores @ V                                │
│ └─ Combine heads → (1, 3840, 2048)                    │
│                                                        │
│ Output Projection:                                     │
│ └─ W_o @ output → (1, 3840, 2048)                    │
└────────────────────────────────────────────────────────┘

FLOPS per Attention Block:
├─ Projections: Q,K,V,O = 4 × (3840 × 2048 × 2048) ≈ 64B FLOPs
├─ Attention matmul: Q @ K^T = 3840 × 3840 × 256 ≈ 3.8B FLOPs
├─ Softmax & scale: ≈ 3.8B FLOPs
└─ Attention @ V: 3840 × 3840 × 256 ≈ 3.8B FLOPs
Total per attention block: ~75B FLOPs (with KV cache reuse)

================================================================================
                        DIFFUSION LOOP (3-step)
================================================================================

FOR step in [1, 2, 3]:

    Input to DiT:
    ├─ Noisy latents: (1, 16, 48, 80) [noise at timestep t]
    ├─ Timestep: t ∈ [1, 1000] encoded as sinusoidal
    ├─ Text conditioning: 77 tokens × 2048
    └─ Camera pose: encoded as spatial bias

    Forward Pass:
    ├─ Patchify & embed input
    ├─ 28 × DiT Block:
    │  ├─ Attention (with KV cache from step 1)
    │  ├─ MLP (gated, conditioned on timestep)
    │  └─ Residual connection
    └─ Output projection → (1, 16, 48, 80)

    Denoising Step:
    ├─ Predicted noise ε(x_t, t)
    ├─ Update: x_{t-1} = (x_t - sqrt(1-β_t) × ε) / sqrt(β_t)
    │          [DDPM reverse process]
    └─ Timestep t → t-1

    KV Cache:
    ├─ Step 1: Compute & store K, V tensors
    ├─ Step 2: Load cached K, V (no recompute)
    ├─ Step 3: Load cached K, V (no recompute)
    └─ Result: 2/3 fewer attention FLOPs

3 Denoising Steps:
├─ Total forward passes: 3
├─ Total backward passes: 0 (inference only)
├─ Total FLOPs: 3 × (28 × 75B) ≈ 6.3T FLOPs
├─ Time: ~1800ms on RTX 5090
└─ Throughput: ~3.5 TFLOPS (measured)

                    PARAMETER BREAKDOWN (16.26B)
================================================================================

Embeddings & Projections:
├─ Input patchify: 16 × 16 × 16 = 4,096 params
├─ Output projection: 2048 × 16 = 32,768 params
├─ Timestep embedding: 256 params
├─ Sinusoidal pos encoding: 0 (no params, computed)
└─ Total: ~40K params

Transformer Blocks (28×):
├─ Attention per block: 16.8M params
│  └─ Q,K,V,O: 4 × (2048 × 2048) = 16.8M
├─ MLP per block: 21.5M params
│  └─ Linear 1: 2048 × 5376 = 11M
│  └─ Linear 2: 5376 × 2048 = 11M
│  └─ Gate: 2048 params
├─ LayerNorm per block: 8K params (2 norms × 4096)
└─ Per block: 38.3M
└─ 28 blocks: 1.073B params

Text Conditioning (Cross-Attention):
├─ Separate cross-attention heads
├─ Text projection: 768 → 2048
└─ Projection: 768 × 2048 = 1.6M params

Remaining:
├─ Output layernorm: 4K params
├─ Various biases & embeddings: ~10M
└─ Total misc: ~14M params

TOTAL: ~1.073B + 14M + 1.6M + 40K ≈ 1.088B (core)
       ↓
       But actual checkpoint: 16.26B
       (includes all 28 blocks with full projections)

Note: 16.26B includes all weight matrices fully stored.
      Actual model complexity much lower due to parameter sharing.

================================================================================
                    INFERENCE CHARACTERISTICS
================================================================================

Input:
├─ 16 video frames (latent space)
├─ 24 fps video (each frame = 1/24 second)
├─ Total temporal span: 16/24 = 0.67 seconds per input

Output:
├─ Predicted noise (same shape as input)
├─ Used in reverse diffusion process

Computational Cost:
├─ Per-step: ~1800ms / 3 steps ≈ 600ms per step
├─ Dominated by attention: O(n²) in sequence length
├─ KV cache saves ~2/3 of computation
└─ Without cache: ~1600ms per step (4800ms total)

Memory Cost:
├─ Model weights: 14 GB (always resident)
├─ Activations (forward): ~1 GB
├─ KV cache: 2.5 GB (reused across steps)
├─ Intermediate buffers: ~1 GB
└─ Total per chunk: ~20 GB

Quality:
├─ 3-step diffusion (vs standard 50-step)
├─ No classifier-free guidance (CFG)
├─ Trained via knowledge distillation from teacher
├─ Competitive quality on VBench, WBench benchmarks
└─ Speed-quality tradeoff: 0.71× realtime, high quality
